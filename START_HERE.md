# 🚀 Uploading the complete research repository

This folder is the **complete local repository content**. It contains all original research files (raw data, notebooks, scripts) plus the organized pipeline, results, and the **research highlight**.

## Quick start for teammates

**You do not need to run any code just to read the results.**

1. Read [`RESEARCH_HIGHLIGHT.md`](RESEARCH_HIGHLIGHT.md) for a concise summary of findings, metrics, and the capping comparison.
2. See [`decisions.md`](decisions.md) for the justification of modeling choices (household split, features, metrics, capping).
3. Open any committed plots or result CSVs directly.

To reproduce or modify the analysis, open and run [`Main_File.ipynb`](Main_File.ipynb). That notebook is the main entry point; it calls the modular scripts as needed.

## Recommended: GitHub Desktop (Mac or Windows)

GitHub browser uploads permit **up to 100 files per batch**. The raw dataset contains hundreds of files, so GitHub Desktop is simpler.

**If you have already created an empty online repo:**

1. Install [GitHub Desktop](https://desktop.github.com/), sign in to your GitHub account.
2. In GitHub Desktop choose **File → Clone repository** and select your empty repo.
3. Open the cloned folder and copy **everything** from this package into it (including hidden `.gitignore`).
4. Return to GitHub Desktop: review changed files, enter a commit summary (e.g. `Add data, modular pipeline, and research highlight`), click **Commit to main**, then **Push origin**.
5. Refresh the repository page on GitHub.

**If you have NOT created the online repo yet:**  
GitHub Desktop → File → New repository → choose this folder → commit → **Publish repository**. Prefer **Private** until team and data-sharing checks are complete.
